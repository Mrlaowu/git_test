✨ 系统特性

  • 定时触发 - 每天北京时间 13:00 自动运行，无需人工干预
  • 多源聚合 - 从 RSS、Hacker News、GitHub Trending 等多个权威来源收集信息
  • 智能过滤 - 自动识别 AI 相关内容，去除无关信息
  • Issue 推送 - 自动创建标签化 GitHub Issue，便于检索和归档
  • 易于定制 - 支持修改触发时间、添加 RSS 源、配置邮件推送等
  • 完全开源 - 代码透明，支持二次开发和社区贡献

🚀 快速开始

  • 1. 查看文件 - 访问 feature/ai-daily-digest 分支查看所有文件
  • 2. 手动测试 - 进入 Actions 标签页，点击 "Run workflow" 手动触发
  • 3. 查看日报 - 在 Issues 标签页过滤 daily-digest 标签查看日报
  • 4. 合并启用 - 创建 Pull Request 合并到主分支，正式启用定时任务

⚙️ 配置选项

  • 修改触发时间 - 编辑 .github/workflows/ai-daily-digest.yml 中的 cron 表达式
  • 添加 RSS 源 - 在 .github/scripts/fetch_ai_news.py 中配置新源
  • 启用邮件推送 - 配置 Secrets 并在工作流中添加邮件步骤
  • 集成钉钉/企业微信 - 编辑采集脚本添加 Webhook 调用
